Synth Workspace Bridge

Pair this extension with your Synth Workspace page. The pairing token lets the extension trust that origin; it is not a provider key and nothing else is stored here.

1. Allow provider requests

The extension only reaches https providers and localhost services. Chrome asks once for the host permission.

2. Pair with the workspace

Paste the extension id and token into Settings → Browser extension in Synth Workspace. Pairing is one-time; regenerate to revoke old pages.
